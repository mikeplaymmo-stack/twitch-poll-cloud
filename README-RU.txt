ОБЛАЧНАЯ ПАНЕЛЬ ОПРОСОВ TWITCH · 0.3.0

СТАТУС
Это подготовленный облачный прототип. Код и локальные проверки выполнены;
вход и отправка голоса именно из Cloudflare на настоящем Twitch ещё не подтверждены.
Развёртывание в твоём Cloudflare не выполнено: доступа к нему в этой работе нет.

ЧТО УМЕЕТ
— Собственная панель в браузере с паролем.
— Один экземпляр облачного Chrome; аккаунты изолированы друг от друга.
— Добавление логинов и ручной вход в каждый аккаунт через Cloudflare Live View.
— Зашифрованное сохранение cookies и localStorage для восстановления входа.
— 2–5 вариантов, проценты, доля участвующих аккаунтов, «Поровну» и «Случайно».
— 1–3 одновременно обрабатываемых аккаунта; остальные проходят по очереди.
— Ожидание опроса на выбранном канале и отправка через видимый интерфейс Twitch.
— Опциональное ожидание следующих разных опросов до заданного лимита времени.
— Индивидуальные результаты: подтверждено / не подтверждено / пропущено.
— Остановка и закрытие браузера по лимиту. На Windows программу запускать не нужно.

НАСТРОЙКА ЧЕРЕЗ БРАУЗЕР, БЕЗ NODE.JS И ТЕРМИНАЛА НА WINDOWS
1. Создай отдельный приватный репозиторий GitHub.
2. Распакуй архив. В GitHub выбери Add file → Upload files и загрузи содержимое
   папки twitch-poll-cloud с сохранением структуры папок.
   В корне репозитория должны оказаться package.json, package-lock.json,
   wrangler.jsonc, папки src, public, scripts, tests.
   node_modules и .wrangler загружать не нужно; их в архиве нет.
3. В Cloudflare открой Workers & Pages → Create application и подключи этот
   GitHub-репозиторий. Используй Worker, не Pages.
   Имя Worker: twitch-poll-cloud (такое же, как name в wrangler.jsonc).
   Build command: npm ci && npm run build
   Deploy command: npx wrangler deploy
   Root directory: корень репозитория.
   Версия Node.js для сборки: 22 или новее.
4. Разверни Worker. Wrangler создаст привязки и миграцию из wrangler.jsonc:
   BROWSER → Browser Run;
   PANEL → Durable Object класса PollPanel, SQLite, миграция v1.
   Это отдельный Worker. Старый чат-Worker заменять этим архивом не нужно.
5. Открой secrets-generator.html из архива в браузере и нажми «Создать».
   Он работает без сети. Скопируй значения в Cloudflare:
   Worker → Settings → Variables and Secrets → Add → тип Secret.
   PANEL_PASSWORD — пароль входа в новую панель (минимум 16 символов).
   SESSION_KEY — ключ шифрования, ровно 64 символа 0–9 / a–f.
   Сохрани значения в своём менеджере паролей; нажми Deploy в Cloudflare.
   Не добавляй секреты в репозиторий, обычные Variables или переписку.
6. Открой HTTPS-адрес Worker и введи PANEL_PASSWORD.

Если в Cloudflare изменились названия кнопок, важны те же действия:
подключить GitHub к Workers Builds, развернуть по wrangler.jsonc, добавить два Secret.
Исходный код и готовый dist/worker.mjs находятся в архиве. Один вставленный
worker.mjs без Browser binding и миграции Durable Object работать не будет.

ПЕРВАЯ ПРОВЕРКА: ОДИН АККАУНТ
1. Добавь логин Twitch.
2. Нажми «Войти в Twitch», затем «Открыть облачное окно».
3. В облачном окне вручную войди в тот же аккаунт. Если Twitch требует код,
   введи его там. Панель не обходит проверки входа.
4. Вернись в панель и нажми «Я вошёл — проверить и сохранить».
   Twitch /oauth2/validate должен подтвердить ожидаемый логин.
5. Впиши канал. Кнопка «Проверить канал» открывает чат в сохранённой сессии.
   Убедись, что виджет опроса виден. Закрой облачный браузер кнопкой в панели.
6. Выбери один аккаунт. Укажи ровно столько вариантов, сколько у опроса.
   Для проверки одного ответа можно задать 100 / 0.
7. На первую проверку поставь лимит 1–2 минуты и 1 аккаунт одновременно.
   Если опрос уже идёт, включи «Включить уже открытый опрос».
   По умолчанию панель ждёт новый опрос после подключения.
8. Нажми «Запустить ожидание». В результате ищи «Подтверждено» и проверь
   голос в Twitch. «Не подтверждено» не означает, что голос точно не прошёл:
   кнопка могла сработать, поэтому автоматического повторного клика нет.
9. Только после этой проверки добавляй остальные аккаунты: сначала 2–3, затем 20.

Если ссылка Live View не открылась, проверь Browser Run → Live Sessions в
Cloudflare. Ссылка действительна для начала подключения 5 минут. Окно входа
ограничено 10 минутами. «Новое окно» выдаст новую ссылку и откроет страницу входа.
Нажать крестик у диалога недостаточно для закрытия облачного браузера:
используй «Закрыть облачный браузер» или «Остановить».

ПРОЦЕНТЫ
20 аккаунтов и 30 / 20 / 25 / 25 → 6 / 4 / 5 / 5 попыток голосования.
При доле участников 50% из 20 аккаунтов выбираются 10 случайных аккаунтов.
Дробные количества округляются методом наибольших остатков, сумма всегда
равна числу участников. При равенстве остатков выбор случайный.
Проценты относятся к распределению попыток твоих аккаунтов. Остальные зрители
и неудачные попытки меняют фактический итог опроса.
Поле текста у варианта необязательно. Если заполнено, текст должен совпасть.
Несовпадение количества вариантов или подписей блокирует этот опрос.

ПОВТОРНЫЕ ОПРОСЫ И ВРЕМЯ
По умолчанию один запуск обрабатывает один подходящий опрос и закрывает браузер.
При включении продолжения панель ждёт новые опросы до лимита, максимум 100
разных опросов за запуск. С одинаковыми вопросом и вариантами голосует только
один раз в рамках запуска — надёжного ID опроса у DOM-виджета нет.
Вопросы с другим числом вариантов будут пропущены; они не перенастраивают проценты.
Лимит работы: 1–240 минут, по умолчанию 5. Это не круглосуточный бессрочный запуск.
Время очереди: 10–180 секунд, по умолчанию 60. Все 20 аккаунтов могут не успеть
в короткий опрос: нужно измерить загрузку и скорость на реальном канале.
Небольшая задержка закрытия возможна, пока завершается уже начатый сетевой вызов.
После перезапуска обработчика текущая очередь прерывается. Уже начатая отправка
остаётся «Не подтверждено», сама не повторяется; новый запуск включает пользователь.

ОГРАНИЧЕНИЯ ПРОТОТИПА
— Twitch может отклонить вход из облака. Совместимость пока не проверена.
— Официальный Twitch API не предоставляет endpoint для голоса зрителя;
  используется интерфейс сайта. Изменение разметки может потребовать обновления.
— Видеопоток не открывается: используется отдельная страница чата канала.
— Свёрнутый или отсутствующий виджет может не обнаружиться автоматически.
— Виджет с упоминанием Bits, баллов или дополнительных голосов пропускается.
  В этой версии нет расходования баллов/Bits или повторных платных голосов.
— Для разных аккаунтов создаются отдельные контексты в одном браузере; это не
  отдельные сетевые подключения с разными IP. Прокси из старой панели не перенесены.
— Из старой чат-панели аккаунты и токены автоматически не импортируются.
  В этой версии логины добавляются здесь, вход сохраняется отдельно.
— Панель рассчитана на одного владельца; многопользовательских ролей нет.
— Если поменять SESSION_KEY, старые сохранённые входы нельзя расшифровать.
  Смена PANEL_PASSWORD завершит сессии входа в панель; сессии Twitch сохранятся.

ОПЛАТА
Пробный Free: до 10 минут суммарного браузерного времени в день.
Workers Paid: базово $5/месяц; Browser Run включает 10 браузер-часов в месяц,
затем $0.09/час. При одном экземпляре браузера отдельной надбавки за его
параллельные контексты нет. Дополнительно применяются лимиты и тарифы Workers,
Durable Objects и хранения. Вход, проверки и ожидание тоже используют браузерное
время. Панель не является жёстким денежным лимитом Cloudflare.
Проверяй актуальные тарифы в Cloudflare перед включением платного плана.

ДЛЯ РАЗРАБОТЧИКА
npm ci
npm test
npm run build
npx wrangler deploy --dry-run --outdir dist/check
npm run deploy
Команды можно выполнять в облачной среде сборки. Постоянный ПК не нужен.
Код голосования: src/browser.js и src/poll-dom.txt.
Очередь и ограничения: src/engine.js. Проценты: src/core.js.
Секреты и аутентификация: src/security.js, src/worker.js.
Интерфейс: public/index.html, public/style.css, public/app.txt.

ПРОВЕРЕНО
Локальные проверки распределения, шифрования, подписанной сессии панели,
размера запросов, CSRF, очереди на 20 аккаунтов с подставным браузером,
остановки, неопределённого результата, перезапуска и исключения одинаковых опросов.
Сборка esbuild и Wrangler deploy --dry-run без публикации.
Интерфейс открыт в локальном Chromium с тестовыми аккаунтами: проверены вход
в саму панель, выбор 20 аккаунтов, 30/20/25/25, доля 50%, блокировка неверной
суммы процентов, отсутствие ошибок JavaScript и ширина на экране 390 px.
Это локальная проверка интерфейса и обработчиков, а не подтверждение работы
Browser Run. Локальный wrangler dev в этой среде не запустился из-за системной
ошибки uv_interface_addresses; облачная проверка остаётся отдельным этапом.
Реальные Browser Run / Twitch / 20 аккаунтов: не проверены.
